# Amazon Clone
A responsive Amazon homepage clone built using <b>HTML</b> and<b>CSS</b>.This project replicates the look and feel of Amazon's landing page while improving my frontend development skills.<br>
<b>#Features</b>
-Amazon-inspired responsive UI
-Navigatin Bar
-Search Bar
-Product Cards
-Multiple Shopping Sections
-Footer with Quick Links
-Clean and Modern Layout<br>

<b>##Technologies Used</b>
-HTML 5
-CSS 3
-Flexbox
-CSS Grid
-Responsive Design<br>
